# LAVENDER — права стримера

Стример МОЖЕТ:
- добавлять новых игроков;
- добавлять новые гильдии;
- создавать матчи;
- добавлять kills / deaths / headshots.

Стример НЕ МОЖЕТ:
- удалять игроков;
- удалять гильдии;
- редактировать существующих игроков;
- редактировать существующие гильдии;
- вручную менять ELO;
- вручную менять wins / losses.

ELO, победы и поражения остаются автоматическими по результатам матчей.

Администратор сохраняет полный доступ.
