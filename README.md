# LAVENDER PRO 7.1 — STREAMER EDITOR

В этой версии стример получает права редактора игроков и матчей.

Стример может:
- добавлять игроков в общий рейтинг;
- менять ELO, победы, поражения, убийства и смерти;
- редактировать игроков;
- удалять игроков;
- создавать матчи;
- редактировать матчи и счет;
- удалять матчи;
- выбирать существующие гильдии для игроков и матчей;
- использовать свою Streamer Zone и персональный OBS Overlay.

Добавленный игрок сразу попадает в публичный рейтинг S/A/B/C/D/E/F.
Ранг рассчитывается автоматически по ELO.

Админ по-прежнему единственный, кто может:
- добавлять/удалять стримеров;
- управлять гильдиями;
- управлять турнирами и новостями;
- пользоваться общей Admin Panel и глобальной Stream Studio.
