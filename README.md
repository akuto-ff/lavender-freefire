# LAVENDER PRO 7.2 — STREAMER GUILDS

Теперь стримеры могут добавлять, редактировать и удалять гильдии.

Стример может:
- создать гильдию;
- задать название и тег;
- загрузить логотип/аватар;
- выбрать регион;
- указать капитана;
- задать ELO, победы и поражения;
- добавить описание;
- редактировать и удалять гильдии;
- добавлять игроков в созданные гильдии;
- использовать эти гильдии при создании матчей.

После добавления гильдия сразу появляется в публичном разделе и в списках выбора для игроков и матчей.
