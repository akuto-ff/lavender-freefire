# LAVENDER PRO 7.3 — STREAMER OVERLAY PLAYERS + AUTO ELO

Главные изменения:

## Стримерский Overlay
В Streamer Zone стример теперь может:
- выбрать матч;
- отдельно выбрать игрока слева в оверлее;
- отдельно выбрать игрока справа в оверлее;
- прямо из Streamer Zone нажать "+ Добавить нового игрока";
- после добавления игрок сразу доступен в выпадающем списке оверлея;
- использовать свой персональный OBS URL.

Если игроки не выбраны вручную, Overlay берёт игроков из выбранного матча.

## Автоматический ELO
Когда матч переводится в статус FINAL:
- определяется победитель по счёту;
- ELO двух выбранных игроков пересчитывается автоматически;
- победителю добавляется ELO, проигравшему снимается;
- победителю +1 победа, проигравшему +1 поражение;
- используется стандартная Elo-формула с K=32;
- перерасчёт одного матча выполняется только один раз;
- в карточке матча показывается изменение ELO.
