LAVENDER PRO 6.1 ADMIN STABLE

Исправлена главная причина проблемы:
Free Render может засыпать/перезапускать процесс. В 6.0 админ-сессия жила в RAM,
поэтому после перезапуска сервер забывал вход, и добавление игрока/матча получало 401.

В 6.1:
- админ-сессия подписанная и не зависит от RAM;
- после входа выполняется /api/admin/ping;
- UI сразу перерисовывается как ADMIN;
- кнопки добавления появляются корректно;
- при 401 сайт сам просит войти заново;
- запросы идут cache:no-store;
- добавление игроков/матчей/гильдий проверяется сервером.

Render Environment:
LAVENDER_ADMIN_USER = логин
LAVENDER_ADMIN_PASSWORD = пароль
LAVENDER_SESSION_SECRET = придумай длинную случайную строку (рекомендуется)
NODE_ENV = production

Проверка после deploy:
1) /health -> version 6.1.0
2) войти Admin
3) нажать "Проверить админ"
4) должно быть "Админ работает • v6.1.0"
5) создать тестового игрока и матч.
